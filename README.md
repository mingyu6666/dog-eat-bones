# 🐶 小狗吃骨头（网页版小游戏）

休闲跳跃小游戏：白色斑点小狗（便便狗）叼着骨头向上攀登，踩中骨头就会叼到嘴里继续弹起，
踩空就会摔落。碰到狗粮会触发超高弹跳，蹦得特别高！小狗跳起来时会有两腿往前蹬的动态动作。
越往高处，骨头、狗粮越小、间距越大，积分旁实时记录跳跃高度，挑战你的操作与节奏感。

纯 HTML5 Canvas 实现，零依赖、零构建，打开即玩。全部画面使用你提供的素材原图：
公园背景图全屏铺底、骨头/狗粮透明精灵、设定图抠出的便便狗（站立帧 + 腾空蹬腿帧双动画）。

## ✨ 玩法

- **点击/触摸开始**：小狗自动向上弹跳
- **左右移动鼠标（悬停即跟随）**：控制小狗的水平位置，瞄准下一个骨头（桌面端无需按住；手机端按住屏幕左右拖动）
- **踩中骨头**：立马叼到嘴里，继续弹起，+1 分（金骨头 +5 分）
- **碰到狗粮**：触发超高弹跳（蹦得特别高），+5 分
- **踩空**：小狗摔落，游戏结束
- **高度记录**：HUD 实时显示跳跃高度（米），历史最高高度一并保存
- **难度递增**：分数越高，骨头、狗粮越小、层间距越大，20 分后还会出现双骨头选择

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可游玩（桌面端鼠标悬停即跟随；手机浏览器支持触摸）。无需安装任何工具或依赖。

## 🎮 游戏逻辑速览（便于二次开发）

| 模块 | 说明 |
| --- | --- |
| 物理 | 重力 `G=1100` px/s²，踩骨头弹起初速 `v=√(2·G·层距)×1.15`（留高度余量） |
| 狗粮弹跳 | 初速再 ×1.85，蹦得特别高，+5 分 |
| 跳跃动画 | 上升阶段（vy<0）切换腾空蹬腿帧 dog2.png，下落/待机用站立帧 dog.png |
| 碰撞 | 小狗脚部跨过骨头层中心线时判定水平距离（容差 20px） |
| 难度曲线 | 层距 `120→230`，骨头半径 `44→20`，狗粮 `34→14` |
| 高度记录 | 相机上升高度按 40px=1m 换算，最高高度 localStorage 缓存 |
| 音效 | WebAudio 程序化合成（命中/狗粮/失败），无外部音频文件 |
