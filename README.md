# 🐶 小狗吃骨头（微信小程序版）

休闲跳跃小游戏：白色斑点小狗（便便狗）叼着骨头向上攀登，踩中骨头就会叼到嘴里继续弹起，
踩空就会摔落。碰到狗粮会触发超高弹跳，蹦得特别高！越往高处，骨头、狗粮越小、间距越大，
积分旁边实时记录跳跃高度，挑战你的操作与节奏感。

纯原生微信小程序实现，零第三方依赖，全部画面用 Canvas 2D 程序化绘制（公园背景图 + 白天天空、
骨头、狗粮、斑点小狗），音效为脚本合成，可直接在微信开发者工具中运行。

## ✨ 玩法

- **点击/触摸开始**：小狗自动向上弹跳
- **左右移动鼠标（悬停即跟随）**：控制小狗的水平位置，瞄准下一个骨头（桌面端无需按住；手机端按住屏幕左右拖动）
- **踩中骨头**：立马叼到嘴里，继续弹起，+1 分（金骨头 +5 分）
- **碰到狗粮**：触发超高弹跳（蹦得特别高），+5 分
- **踩空**：小狗摔落，游戏结束
- **高度记录**：HUD 实时显示跳跃高度（米），历史最高高度一并保存
- **难度递增**：分数越高，骨头、狗粮越小、层间距越大，20 分后还会出现双骨头选择
- **本地记录**：历史最高分与最高高度保存在本地缓存；支持微信分享好友/朋友圈

## 🚀 本地运行

**方式一：浏览器立即试玩（无需任何工具）**

直接用浏览器打开 `preview/index.html` 即可玩（桌面端鼠标悬停即跟随，无需按住；手机浏览器支持触摸）。游戏逻辑与微信小程序完全一致，音效用 WebAudio 实时合成，进度存于浏览器本地。

**方式二：微信开发者工具运行**

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 打开开发者工具 → 导入项目 → 选择本目录
   - AppID 可先选择「测试号」（`project.config.json` 已配置为游客模式 `touristappid`，导入时也可改用自己的 AppID）
3. 编译后即可在模拟器中游玩（推荐用「真机调试」体验手感）

> 提示：游戏依赖 `wx.getWindowInfo()`（基础库 2.20.1+）与 Canvas 2D 接口，开发者工具请使用较新的基础库版本。

## 🎮 游戏逻辑速览（便于二次开发）

| 模块 | 位置 | 说明 |
| --- | --- | --- |
| 物理 | `update()` | 重力 `G=1100` px/s²，踩骨头弹起初速 `v=√(2·G·层距)×1.15`（留高度余量） |
| 狗粮弹跳 | `hitFood()` | 初速再 ×1.85，蹦得特别高，+5 分 |
| 碰撞 | `update()` | 小狗脚部跨过骨头层中心线时判定水平距离（容差 20px） |
| 难度曲线 | `nextGap()` / `bellRadius()` / `foodRadius()` | 层距 `120→230`，骨头半径 `44→20`，狗粮 `34→14` |
| 高度记录 | `update()` | 相机上升高度按 40px=1m 换算，最高高度本地缓存 |
| 相机 | `update()` | 只向上跟随（坠落时锁定，保证能掉出屏幕） |
| 渲染 | `render()` | 背景图/天空/云/骨头/狗粮/小狗/粒子全部 Canvas 绘制 |
| 音效 | `initAudio()` | `wx.createInnerAudioContext` 复用三个实例 |
| 最高分/最高高度 | `gameOver()` | `wx.setStorageSync` 本地缓存 |
